## 📌 Projects & Coursework Overview

### 1. 🏛️ Group Project: Smart Campus Resource Booking System (`group-project/`)
An enterprise-grade, real-time campus facility and academic resource reservation platform built with:
- **Frontend**: React 18, Vite 6, Modern CSS with custom UI tokens
- **Backend**: Node.js, Express 4, RESTful APIs, JWT Auth
- **Database**: MongoDB with Mongoose 8 (includes zero-config in-memory MongoDB fallback)
- **Validation & Security**: Zod, Bcrypt, Helmet, CORS
- **Testing**: Vitest & Supertest

See the [Group Project README](group-project/README.md) for detailed setup and usage instructions.
